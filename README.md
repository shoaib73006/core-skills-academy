# Core Skills Academy 🎯

A Streamlit-based learning and assessment platform that helps learners practice core programming concepts, track learning progress, and identify topics that need improvement.

## Features

- **Learning Dashboard:** View total topics, completed topics, and overall progress.
- **Learning Modules:** Track progress across Python, SQL, APIs, backend development, and code quality.
- **Skills Assessment:** Take a multiple-choice quiz and review correct answers.
- **Weak Topic Analysis:** Identify topics with lower quiz accuracy.
- **Quiz History:** Review previous attempts and compare scores.

## Tech Stack

- Python
- Streamlit
- SQLite
- Pandas

## Run Locally

1. Clone this repository:

   `git clone https://github.com/shoaib73006/core-skills-academy.git`

2. Open the project directory:

   `cd core-skills-academy`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `python -m streamlit run app.py`

5. Open the local URL shown in your terminal.
